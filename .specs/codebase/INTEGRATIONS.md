# External Integrations

**Analyzed:** 2026-05-25

## Authentication

**Service:** Better Auth
**Purpose:** Email/password login, session management, Next.js handlers, cookies.
**Implementation:**

- Config: `src/infra/auth/server.ts`
- Browser client: `src/infra/auth/client.ts`
- Route handler: `src/app/api/auth/[...all]/route.ts`
- Session helpers: `src/infra/auth/session.ts`

**Configuration:**

- `BETTER_AUTH_SECRET`
- `BETTER_AUTH_URL`
- Better Auth Prisma adapter configured with provider `postgresql`

**Authentication:** Credential provider using email/password. Public signup is disabled with `emailAndPassword.disableSignUp: true`.

## Database

**Service:** PostgreSQL 17
**Purpose:** Persistent storage for users, sessions, accounts, verification records, and future domain data.
**Implementation:**

- Local service: `docker-compose.yml`
- ORM schema: `prisma/schema.prisma`
- Client: `src/infra/db/prisma.ts`

**Configuration:**

- `POSTGRES_DB`
- `POSTGRES_USER`
- `POSTGRES_PASSWORD`
- `POSTGRES_PORT`
- `DATABASE_URL`

**Authentication:** Database user/password through connection string.

## ORM

**Service:** Prisma 7
**Purpose:** Schema, migrations, generated client, and typed data access.
**Implementation:**

- `prisma.config.ts`
- `prisma/schema.prisma`
- generated client output: `src/generated/prisma`

**Configuration:** `prisma.config.ts` reads `DATABASE_URL` and migration path.

## API Integrations

### Better Auth HTTP API

**Purpose:** Auth endpoints for sign-in/sign-out/session flows.
**Location:** `src/app/api/auth/[...all]/route.ts`
**Authentication:** Better Auth session cookies.
**Key endpoints:** Generated by Better Auth via `toNextJsHandler(auth)`.

## Email

No production email provider is implemented yet. Invitation delivery should use the configured adapter mode.

**Planned invitation configuration:**

- `APP_BASE_URL`: public application base URL used to build absolute invitation links.
- `INVITATION_EMAIL_DELIVERY`: delivery mode. Use `console` in local/test until SMTP/provider delivery is implemented.
- `INVITATION_EMAIL_FROM`: sender label/address for invitation emails.
- `SMTP_HOST`: optional SMTP host for future `smtp` delivery.
- `SMTP_PORT`: optional SMTP port for future `smtp` delivery.
- `SMTP_USER`: optional SMTP username for future `smtp` delivery.
- `SMTP_PASSWORD`: optional SMTP password for future `smtp` delivery.
- `SMTP_SECURE`: optional SMTP TLS flag for future `smtp` delivery.
